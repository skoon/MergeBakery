# Task T4.9: Bake-finished notifications

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Bake`, `BakeSlotRef`), src/ui/saveStorage.ts (`KeyValueStorage`), src/ui/kitchenSheet.ts (T4.4, the `.kitchen-extras` div), src/ui/store.ts, src/main.ts, docs/briefs/working-rules.md.

Goal: Players who opt in get one browser notification when a bake finishes while the game's tab is hidden.

Files to create or edit: src/ui/settings.ts, src/ui/settings.test.ts, src/ui/bakeNotifier.ts, src/ui/bakeNotifier.test.ts, src/ui/kitchenSheet.ts (the toggle only), src/main.ts. Do not edit any other file.
Contract:

```ts
// src/ui/settings.ts (T5.9 later adds more settings here)
export const SETTINGS_KEY = 'rise-and-shine-settings';
export interface Settings {
  notifications: boolean;
}
export const DEFAULT_SETTINGS: Settings = { notifications: false };
/** Missing → DEFAULT_SETTINGS. Unparseable or wrong shape → console.error and DEFAULT_SETTINGS. Storage that throws → console.error and DEFAULT_SETTINGS. */
export function readSettings(storage: KeyValueStorage): Settings;
/** console.error when storage throws. */
export function writeSettings(
  storage: KeyValueStorage,
  settings: Settings,
): void;

// src/ui/bakeNotifier.ts
export function bakeKey(slot: BakeSlotRef, bake: Bake): string; // `${oven}:${slot}:${endsAt}`
/** Bakes with endsAt <= now whose key isn't in `notified`, in oven and slot order. */
export function finishedBakes(
  data: GameData,
  state: GameState,
  now: Timestamp,
  notified: ReadonlySet<string>,
): { key: string; recipeName: string }[];
export interface NotifierOptions {
  isHidden: () => boolean;
  notificationsOn: () => boolean;
  notify: (title: string) => void;
}
/**
 * Every 1000 ms: for each finished bake not yet seen, calls notify(`${recipeName} is ready!`)
 * if isHidden() and notificationsOn(); either way marks it seen, so a bake that finished while
 * the tab was visible never notifies later. Returns a stop function.
 */
export function startBakeNotifier(
  store: GameStore,
  clock: () => Timestamp,
  options: NotifierOptions,
): () => void;
```

- **Toggle:** in `mountKitchen`, add a checkbox "Notify me when bakes finish" to `.kitchen-extras`, checked from `readSettings(localStorage)`. Turning it on calls `Notification.requestPermission()` when permission isn't already 'granted'; if the result isn't 'granted', uncheck it and keep the setting off. Save changes with `writeSettings`. When the browser has no `Notification` API, hide the toggle.
- **main.ts:** start the notifier with `isHidden: () => document.visibilityState === 'hidden'`, `notificationsOn: () => readSettings(localStorage).notifications && Notification.permission === 'granted'` (false when `Notification` is undefined), and `notify: (title) => new Notification(title)`. Small Edit calls only.

Rules: no edits to types.ts; follow docs/briefs/working-rules.md. Test the notifier with `vi.useFakeTimers()` and fake options.

Done when: `npx vitest run src/ui/settings.test.ts src/ui/bakeNotifier.test.ts` passes, with tests for: settings defaults, a round trip, corrupt data, and a throwing storage; `finishedBakes` skipping running and already-seen bakes; the notifier firing once for a bake that finishes while hidden, never for one that finished while visible, and not at all when notifications are off; stop ending the interval. `npm run build` succeeds (delete dist/ afterwards). The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
