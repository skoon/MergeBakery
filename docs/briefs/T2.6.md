# Task T2.6: Asset registry

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Item.spriteKey`, `Customer.portraitKey`), src/render/app.ts, docs/briefs/working-rules.md.

Goal: Turn a sprite key into art for both PixiJS and HTML, showing a placeholder instead of failing when the art file is missing.

Files to create or edit: src/render/assets.ts, src/render/assets.test.ts, public/art/\_missing.svg. Do not edit any other file.
Contract:

```ts
export const PLACEHOLDER_KEY = '_missing';
/** `${import.meta.env.BASE_URL}art/${spriteKey}.svg`. Throws when the key has characters other than a-z, A-Z, 0-9, "-" and "_". */
export function assetUrl(spriteKey: string): string;
/**
 * A per-key cache over any loader. get(key) loads assetUrl(key) once. If that load
 * fails, it calls warn once for that key and resolves to the placeholder's value
 * instead. If the placeholder itself fails to load, get rejects.
 */
export function createAssetCache<T>(
  load: (url: string) => Promise<T>,
  warn?: (message: string) => void, // defaults to console.warn
): { get(spriteKey: string): Promise<T> };
/** A shared cache over PixiJS `Assets.load`. */
export function loadTexture(spriteKey: string): Promise<Texture>;
/** Sets img.src to the key's art; if the image fails to load, swaps to the placeholder once and warns. */
export function setImageArt(img: HTMLImageElement, spriteKey: string): void;
```

`_missing.svg` is a 128 × 128 SVG: a light grey rounded square (corner radius 24) with a dark grey "?" in the center.

Tests cover `assetUrl` and `createAssetCache` with a fake loader. `loadTexture` and `setImageArt` are thin wrappers checked in the browser at the phase-end review.

Rules: no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/render/assets.test.ts` passes, with tests for: the URL format; a bad key throwing; a known key loading once however often it's requested; a failing key resolving to the placeholder and warning exactly once; the placeholder failing too (rejects). The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
