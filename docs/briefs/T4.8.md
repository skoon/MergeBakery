# Task T4.8: Catching up after time away

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`GeneratorCharge`, `EnergyState`, `Bake`), src/core/energy.ts (`settleEnergy`), src/core/bakes.ts (T4.2), src/core/save.ts (`SaveFile.savedAt`), src/core/testing.ts, src/main.ts, src/ui/app.css, src/ui/tokens.css, docs/briefs/working-rules.md.

Goal: When a saved game loads, bring its timers up to now and tell the player what happened while they were away.

Files to create or edit: src/core/offline.ts, src/core/offline.test.ts, src/ui/awayCard.ts, src/ui/awayCard.css, src/main.ts. Do not edit any other file.
Contract:

```ts
// src/core/offline.ts
export interface AwaySummary {
  awayMs: number;
  energyGained: number;
  /** Recipes whose bakes finished after savedAt and at or before now, in oven and slot order. */
  bakesFinished: RecipeId[];
  /** Generators (board and Pantry) whose cooldown ended while away. */
  generatorsRecharged: number;
}
/**
 * awayMs = max(0, now − savedAt). Settles energy with settleEnergy. Every generator, on the
 * board or in the Pantry, whose cooldownEndsAt <= now gets full charges from its GeneratorDef
 * and cooldownEndsAt null. Bakes need no change: done is derived from endsAt. A clock earlier
 * than savedAt returns the same state and an all-zero summary.
 */
export function resolveOffline(
  data: GameData,
  state: GameState,
  savedAt: Timestamp,
  now: Timestamp,
): { state: GameState; summary: AwaySummary };
/** True when away at least 60 s and energy was gained, a bake finished, or a generator recharged. */
export function shouldShowAwayCard(summary: AwaySummary): boolean;

// src/ui/awayCard.ts
/** A centered card over the game titled "While you were away", with one line each for: time away ("3 h 12 min", "45 min", or "2 d 4 h"), "+N energy", "<Recipe name> is ready" per finished bake, "N generators recharged" (only lines with something to say), and an OK button that removes the card. */
export function showAwayCard(
  overlayRoot: HTMLElement,
  data: GameData,
  summary: AwaySummary,
): void;
```

In src/main.ts, where the saved game is loaded (`readSave`, from T4.7): when `saved` isn't null, run `resolveOffline(data, saved.state, saved.savedAt, now)` and start from its state; after the UI mounts, call `showAwayCard(overlayRoot, data, summary)` when `shouldShowAwayCard(summary)`. Use small Edit calls only.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md. Import awayCard.css from awayCard.ts; use the tokens.
