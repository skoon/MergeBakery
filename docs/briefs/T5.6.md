# Task T5.6: Recipe Book

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Chain`, `Item.note`, `GameState.discovered`, `rewardedChains`, the `chainCompleted` event), src/core/discovery.ts and its test, src/core/testing.ts, src/render/assets.ts (`setImageArt`), src/ui/navBar.ts (T5.8, `ScreenDef`), src/main.ts, src/ui/tokens.css, docs/briefs/working-rules.md.

Goal: A Recipe Book screen shows every item of every ingredient and baked chain, discovered or not, with Grandma's notes, and completing a chain's page pays its gems once.

Starts after T5.8 (it mounts into T5.8's screen list).

Files to create or edit: src/core/discovery.ts, src/core/discovery.test.ts, src/ui/recipeBookModel.ts, src/ui/recipeBookModel.test.ts, src/ui/recipeBook.ts, src/ui/recipeBook.css, src/main.ts (one line). Do not edit any other file.

## Contract

```ts
// src/core/discovery.ts — extend discover(); its signature doesn't change
/**
 * As today, plus: when this discovery completes a chain — every item in data.chainItems for
 * the item's chain is now discovered — and the chain's completionGems is above 0 and the chain
 * isn't in rewardedChains, adds completionGems to gems, appends the chain to rewardedChains,
 * and returns `chainCompleted { chainId, gems }` after the `discovered` event.
 * Chains with completionGems 0 (generators, bonus items, the Golden Whisk) never pay and are
 * never recorded.
 */
export function discover(
  data,
  state,
  itemId,
): { state: GameState; events: GameEvent[] };

// src/ui/recipeBookModel.ts — pure, no DOM
export interface BookItem {
  itemId: ItemId;
  tier: number;
  spriteKey: string;
  discovered: boolean;
  /** null while undiscovered, so the page doesn't give the name away. */
  name: string | null;
  /** Grandma's note once discovered; null while undiscovered or when she hasn't written one. */
  note: string | null;
}
export interface BookPage {
  chainId: ChainId;
  name: string;
  color: string;
  items: BookItem[]; // by tier
  discoveredCount: number;
  completionGems: number;
  rewarded: boolean;
}
/** One page per ingredient chain, then per baked chain, each in data order. */
export function recipeBookPages(data: GameData, state: GameState): BookPage[];

// src/ui/recipeBook.ts
export function mountRecipeBook(container: HTMLElement, store: GameStore): void;
```

## Behavior

- Tabs across the top, one per page: the chain's name and `discoveredCount/total`, with a tick on rewarded pages. The first tab opens by default.
- The page: a grid of tiles in tier order. A discovered item shows its art, name, tier and Grandma's note, or "Grandma hasn't written about this one yet." when the note is null. An undiscovered one shows its art as a dark silhouette (`filter: brightness(0); opacity: 0.25`), "?" for a name, and its tier.
- Under the grid: "Complete the page: +N gems", or "Page complete" once rewarded.
- Re-render on every store notification. In main.ts, replace the Recipe Book's "Coming soon" `mount` in the screen list with `(container) => mountRecipeBook(container, store)`.
- Import recipeBook.css from recipeBook.ts; use the tokens; fit a 320 px wide screen (tabs scroll sideways if they don't fit).

Rules: `discover` stays pure; no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/core/discovery.test.ts src/ui/recipeBookModel.test.ts` passes, with tests for: discovering the last missing item of a chain paying its gems once, with the `chainCompleted` event after `discovered`; rediscovering or discovering another item not paying again; a chain with completionGems 0 never paying or being recorded; every existing discovery test still passing; `recipeBookPages` giving the ingredient pages then the baked ones, items in tier order, names and notes hidden until discovered, and the counts and `rewarded` flag. `npm run build` succeeds (delete dist/ afterwards). The checks in working-rules.md pass. The phase-end review checks in a browser that discovering an item fills its tile and completing a chain pays once.
