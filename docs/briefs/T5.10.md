# Task T5.10: Audio manager

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/ui/store.ts (`subscribe` gives `(state, events)`), src/core/types.ts (`GameEvent`, the `merged` event), src/render/effects.ts (another store-event listener to follow), src/main.ts, docs/briefs/working-rules.md.

Goal: Sound plays through the Web Audio API on separate music and effects volumes, starting after the player's first tap, beginning with a merge chime that climbs a major scale with the item's tier.

Files to create or edit: src/audio/audioManager.ts, src/audio/audioManager.test.ts, src/audio/mergeChime.ts, src/audio/mergeChime.test.ts, src/main.ts. Do not edit any other file.

**There are no audio files**, so every effect is synthesized from oscillators. Music gets its own volume channel now so Settings (T5.9) can drive it, but no track ships until there is one.

## Contract

```ts
// src/audio/audioManager.ts
export interface ToneSpec {
  /** Hz. */
  freq: number;
  type: OscillatorType; // 'sine' | 'triangle' | 'square' | 'sawtooth'
  /** Start, in ms after the call. Default 0. */
  delayMs?: number;
  durationMs: number;
  /** Peak level before the effects volume, 0–1. */
  gain: number;
}

/** The parts of AudioContext this module uses, so tests can pass a fake. */
export type AudioContextLike = Pick<
  AudioContext,
  | 'currentTime'
  | 'destination'
  | 'state'
  | 'resume'
  | 'createOscillator'
  | 'createGain'
>;

export interface AudioManager {
  /**
   * Creates the context on first call and resumes it. Call from a user gesture;
   * browsers keep audio muted until one. Safe to call repeatedly.
   */
  unlock(): void;
  /** Each clamped to 0–1. Before unlock, remembered and applied on unlock. */
  setVolumes(music: number, effects: number): void;
  /**
   * Plays tones on the effects channel. Each rises to its gain in 5 ms and decays
   * exponentially to silence by its end, so notes never click. Before unlock, does nothing
   * (sounds are dropped, not queued).
   */
  play(tones: readonly ToneSpec[]): void;
}

/** Defaults: music 0.5, effects 0.8. */
export function createAudioManager(
  makeContext?: () => AudioContextLike,
): AudioManager;

// src/audio/mergeChime.ts
/**
 * Tier 1 is C5 (523.25 Hz); each tier climbs one step of the C major scale (C D E F G A B C),
 * so tier 8 is C6 and tier 9 is D6. Throws for a tier below 1.
 */
export function mergeNoteHz(tier: number): number;

/** A short marimba-like note: a sine at the tier's pitch, 180 ms, plus a quiet octave above. */
export function mergeChimeTones(tier: number): ToneSpec[];

/** Plays the chime for every `merged` event, using the merged item's tier. Returns unsubscribe. */
export function startMergeChime(
  store: GameStore,
  audio: AudioManager,
): () => void;
```

The music and effects channels are two `GainNode`s into the destination; every tone goes through the effects one.

## main.ts

Create the manager, call `unlock()` from a one-time `pointerdown` listener on `document`, and call `startMergeChime(store, audio)`. T5.11 adds the other sounds, and T5.9 drives `setVolumes` from Settings.

Rules: no edits to types.ts; follow docs/briefs/working-rules.md. Vitest runs in Node, where there's no `AudioContext`: test with a small fake that records the oscillators and gains it hands out.
