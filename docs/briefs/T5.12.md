# Task T5.12: First-time flow

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`TutorialStep`, the `setTutorialStep` action, `GameEvent`), src/core/merge.ts (`canMerge`), src/core/renovation.ts (T5.2, `availableTasks`), src/render/boardView.ts (`cellCenter`, the canvas), src/ui/counterStrip.ts and src/ui/counterModel.ts (order cards), src/ui/navBar.ts (T5.8, `data-screen`, the router), src/ui/locationView.ts (T5.3), src/ui/store.ts, src/main.ts, docs/briefs/working-rules.md.

Goal: A new player is walked through their first tap, first merge, first order and first renovation by a pointer and one line of text at each step, and can skip it.

Starts after T5.3 and T5.7.

Files to create or edit: src/core/tutorial.ts, src/core/tutorial.test.ts, src/ui/tutorialHints.ts, src/ui/tutorialHints.css, src/ui/counterStrip.ts (a data attribute only), src/main.ts. Do not edit any other file.

## Contract

```ts
// src/core/tutorial.ts
export const TUTORIAL_ORDER: readonly TutorialStep[] = [
  'firstTap',
  'firstMerge',
  'firstOrder',
  'firstRenovation',
  'done',
];

/**
 * Moves tutorialStep forward to `step`. A step at or before the current one returns
 * { ok: true } with the same state object and no events: the tutorial never goes back.
 */
export function setTutorialStep(
  data: GameData,
  state: GameState,
  step: TutorialStep,
): ActionResult;

/**
 * The step these events finish, or `current` when they finish nothing. At most one step:
 * 'firstTap' ends on a non-rare `spawned`, 'firstMerge' on `merged`, 'firstOrder' on
 * `orderDelivered`, 'firstRenovation' on `taskCompleted` (to 'done').
 */
export function tutorialStepAfter(
  current: TutorialStep,
  events: readonly GameEvent[],
): TutorialStep;

/**
 * For a save loaded from before the tutorial existed, which is still on 'firstTap':
 * 'done' when it has any XP or completed tasks (the player is past the basics), else unchanged.
 */
export function catchUpTutorial(state: GameState): TutorialStep;
```

The phase-end review connects `setTutorialStep` to the `setTutorialStep` action in dispatch.ts; don't edit it.

## Behavior

- **Advancing:** after every store notification, when `tutorialStepAfter(current, events)` differs from the current step, dispatch `setTutorialStep` with it. In main.ts, when a save was loaded, dispatch `catchUpTutorial`'s step once at start.
- **The hint** for the current step: a bouncing pointer at a target and a speech bubble near it. The overlay has `pointer-events: none`, so it never blocks the game; only its "Skip tutorial" link takes taps, and it dispatches `setTutorialStep('done')`.
  - `firstTap`: the first non-cobwebbed generator on the board. "Tap the Flour Mill to get some wheat."
  - `firstMerge`: the first pair of board items that `canMerge` allows, pointing from one to the other. "Drag one onto the other to merge them." With no pair on the board, back to the generator: "Tap again for a matching one."
  - `firstOrder`: the first order card whose items are all ready, found by `data-order-id` (add it to each card in counterStrip.ts). "This order is ready. Tap it to deliver." With none ready, the counter strip: "Make what a customer asks for."
  - `firstRenovation`: while the board shows, the Bakery tab (`[data-screen="bakery"]`): "You've earned stars! Spend them in the Bakery." Once the Bakery screen is open, the first available spot: "Tap the glowing spot to fix it up." Before the player can afford the first task, point at the counter instead: "Fill orders to earn stars."
  - `done`: nothing, for good.
- Board targets convert canvas coordinates to page coordinates through the canvas's bounding rect. Reposition on every store notification, on resize, on router changes, and once a second (items move).
- Hints hide while a dialogue scene (T5.5) or a discovery card (T5.7) is open, and while a drag is in progress.
- Import tutorialHints.css; use the tokens; the bubble stays inside a 320 px wide screen.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/core/tutorial.test.ts` passes, with tests for: `setTutorialStep` moving forward, refusing to go back (same state object), and jumping straight to 'done'; `tutorialStepAfter` for each step's finishing event, a rare `spawned` not finishing 'firstTap', events for a later step not skipping ahead, and several events finishing only one step; `catchUpTutorial` for a new save, a save with XP, and a save with a completed task. `npm run build` succeeds (delete dist/ afterwards). The checks in working-rules.md pass. The phase-end review: a new save reaches its first renovation without confusion in a playtest with Scott, and Skip ends the tutorial for good.
