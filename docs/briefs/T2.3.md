# Task T2.3: Dropping an item: merge, swap, or move

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Cell`, `BoardItem`, `ActionResult`, `GameEvent`, `RejectReason`), src/core/board.ts, src/core/merge.ts, src/core/discovery.ts, src/core/locks.ts, src/core/level.ts, src/core/testing.ts, docs/briefs/working-rules.md.

Goal: Resolve dragging the item at one cell onto another cell.

Files to create or edit: src/core/drop.ts, src/core/drop.test.ts. Do not edit any other file.
Contract:

```ts
export function applyDrop(
  data: GameData,
  state: GameState,
  from: CellIndex,
  to: CellIndex,
  now: Timestamp,
): ActionResult;
```

Checks, in order:

1. `from === to` → 'sameCell'.
2. `from` is locked → 'locked'; empty → 'emptyCell'; its item is cobwebbed → 'cobwebbed' (cobwebbed items can't be dragged).
3. `to` is locked → 'locked'.

Outcomes:

- **Move:** `to` is empty. The item moves; `from` becomes empty. No events.
- **Merge:** `canMerge(from item, to item)` (the target may be cobwebbed; a matching merge frees it). `from` becomes empty; `to` holds the next-tier item, not cobwebbed, with full charges if it is a generator (else `generator: null`). Then, in this order: `clearAdjacentLocks(state, to)`; `addXp` with the merged items' tier × `economy.xpPerMergeTier`; `discover` the new item. Events in order: `merged { itemId: <new item>, cells: [to] }`, `cellsUnlocked { cells }` when any opened, then any `discovered` and `levelUp` events.
- **Swap:** otherwise, if the `to` item is cobwebbed → 'cobwebbed'; else the two items trade cells. No events.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md. Task T2.4 later adds the five-item bonus inside `applyDrop`, so keep the merge step in its own small function.

Done when: `npx vitest run src/core/drop.test.ts` passes, with tests for each outcome and each reject reason, including: a drop on a locked cell (rejected); a matching merge into a cobwebbed item (allowed, frees it); a non-matching drop on a cobwebbed item (rejected); merging two generators (the result has full charges); a merge next to a crate (opens it, `cellsUnlocked`); XP and a level-up from a merge; a first-time item (`discovered`); top-tier items swapping instead of merging. The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
