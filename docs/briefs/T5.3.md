## Contract

```ts
// src/ui/locationModel.ts — pure, no DOM
export type SpotState = 'done' | 'available' | 'locked';
export interface SpotView {
  taskId: TaskId;
  name: string;
  starCost: number;
  /** Fractions 0–1 of the scene's width and height. */
  x: number;
  y: number;
  state: SpotState;
  /** afterSpriteKey when done, else beforeSpriteKey. */
  spriteKey: string;
  canAfford: boolean;
}
export interface LocationModel {
  chapterName: string;
  sceneKey: string;
  spots: SpotView[]; // chapter order
  doneCount: number;
  total: number;
  stars: number;
}
export function locationModel(data: GameData, state: GameState): LocationModel;

// src/ui/locationView.ts
export function mountLocationView(
  container: HTMLElement,
  store: GameStore,
): void;
```

`available` means the same as `availableTasks` from renovation.ts; use it, don't re-derive it.

## Behavior

- A header: the chapter's name, "7/20 done", and the player's stars.
- The scene: an image for `sceneKey` (the placeholder until art exists) in a box with a fixed 3:4 aspect ratio, filling the width. Each spot's sprite is drawn at its `x`, `y`, about 22% of the scene's width, centered on the point.
- **Available** spots pulse gently and show a star-cost tag. Tapping one opens a small popover: the task name, "★ 5", and a "Do it" button, disabled with "Need 2 more ★" when unaffordable. "Do it" dispatches `{ type: 'completeTask', taskId }`.
- **Done** spots show their after sprite with no tag. **Locked** spots show their before sprite dimmed, without a tag; tapping one says which task comes first.
- When a task completes, its spot cross-fades from the before sprite to the after sprite over 400 ms, with a small scale bounce. Reduced motion: an instant swap.
- Re-render on every store notification, keeping the cross-fade for the spot that just changed.
- In main.ts, replace the Bakery's "Coming soon" `mount` with `(container) => mountLocationView(container, store)`.
- devTools.ts: add `bakery.stars(n)`, which sets stars to `n` and reloads the same way `give` does, so the review can complete all 20 tasks without grinding orders.
- Import locationView.css; use the tokens; fit a 320 px wide screen.
