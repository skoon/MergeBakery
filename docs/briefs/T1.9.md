# Task T1.9: Seeded RNG and weightedPick

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Rng`, `WeightedEntry`, `ItemId`).

Goal: Add a seeded random number generator (mulberry32) and a weighted picker for spawn and drop tables.

Files to create or edit: src/core/rng.ts, src/core/rng.test.ts. Do not edit any other file.
Contract:

```ts
export function createRng(seed: number): Rng;
export function weightedPick(table: readonly WeightedEntry[], rng: Rng): ItemId;
```

- `createRng` uses mulberry32. Its internal state is one uint32 `a`; each `next()` does `a = (a + 0x6d2b79f5) | 0`, then the standard mulberry32 mixing, and returns a float in [0, 1). `getState()` returns `a >>> 0`, so `createRng(rng.getState())` continues the same sequence.
- `weightedPick` calls `rng.next()` exactly once and returns the `itemId` whose cumulative weight range contains `next() × total weight`. It throws an `Error` if the table is empty, any weight is negative, or the total weight is 0.

Rules: pure functions in src/core; no new dependencies; no edits to types.ts.
