# Task T3.2: Tapping generators and collecting bonus items

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`GeneratorDef`, `GeneratorCharge`, `BoardItem`, `Item.collectReward`, `ActionResult`, `GameEvent`), src/core/board.ts, src/core/energy.ts, src/core/rng.ts, src/core/discovery.ts, src/core/testing.ts, src/data/generators.json, docs/briefs/working-rules.md.

Goal: Tapping a generator spends energy and spawns an ingredient; tapping an energy jar or coin pouch collects it.

Files to create or edit: src/core/generators.ts, src/core/generators.test.ts. Do not edit any other file.
Contract:

```ts
export function tapGenerator(
  data: GameData,
  state: GameState,
  cell: CellIndex,
  rng: Rng,
  now: Timestamp,
): ActionResult;
export function collectBonus(
  data: GameData,
  state: GameState,
  cell: CellIndex,
  now: Timestamp,
): ActionResult;
```

`tapGenerator`, checks in this order:

1. The cell is locked → 'locked'; empty → 'emptyCell'; its item has no `GeneratorDef` → 'notAGenerator'; it is cobwebbed → 'cobwebbed'.
2. Charges: if `charges` is 0 and `cooldownEndsAt` is set and `now >= cooldownEndsAt`, refill to the def's `charges` and clear `cooldownEndsAt`. If `charges` is still 0 → 'coolingDown'.
3. `nearestEmpty(board, cell)` is null → 'boardFull'.
4. `spendEnergy(data, energy, economy.energy.perTap, now)` is null → 'noEnergy'.

Then: call `rng.next()` once; if `next × 100 < rareDrops.chancePercent`, pick from `rareDrops.table`, else from the def's `spawnTable`, with `weightedPick`. Place the item at the nearest empty cell (not cobwebbed; full charges if it is itself a generator, else `generator: null`). Charges − 1; on reaching 0, `cooldownEndsAt = now + cooldownSec × 1000`. Run `discover` on the new item. Events: `spawned { itemId, cell, rare }` followed by any `discovered` event.

`collectBonus`: locked → 'locked'; empty → 'emptyCell'; the item's `collectReward` is null → 'notCollectible'; cobwebbed → 'cobwebbed'. Otherwise add the reward's energy with `addEnergy` and its coins, empty the cell, and return a `collected { itemId, reward }` event.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/core/generators.test.ts` passes, with tests for: a normal tap (energy − 1, charges − 1, item at the nearest empty cell, `spawned` event); each reject reason; running out of charges starting a cooldown; a tap after the cooldown refilling charges; a seeded rare drop (find a seed that rolls one); the same seed giving the same spawn; collecting an energy jar past cap and a coin pouch. The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
