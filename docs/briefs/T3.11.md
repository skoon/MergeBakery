# Task T3.11: Pantry drawer

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Pantry`), src/core/pantry.ts (T3.4), src/ui/store.ts, src/ui/dropZones.ts, src/ui/layout.ts, src/render/boardView.ts (`cellAt`), src/render/assets.ts (`setImageArt`), src/main.ts, src/ui/app.css, src/ui/tokens.css, docs/briefs/working-rules.md.

Goal: Let players stash board items in the Pantry, drag them back out, and buy more slots.

Files to create or edit: src/ui/pantryModel.ts, src/ui/pantryModel.test.ts, src/ui/pantryDrawer.ts, src/ui/pantryDrawer.css, src/main.ts (one line). Do not edit any other file.
Contract:

```ts
// src/ui/pantryModel.ts — pure, no DOM
export interface PantryModel {
  slots: ({ itemId: ItemId; name: string; spriteKey: string } | null)[]; // length = capacity
  used: number;
  capacity: number;
  /** Cost of the next slot; null when every slot is bought. */
  nextSlotCost: number | null;
  canAffordSlot: boolean;
}
export function pantryModel(data: GameData, state: GameState): PantryModel;

// src/ui/pantryDrawer.ts
export function mountPantryDrawer(
  tray: HTMLElement,
  overlayRoot: HTMLElement,
  store: GameStore,
  board: BoardView,
): void;
```

- A "Pantry used/capacity" button at the left end of the tray. It is a drop zone (`registerDropZone`): dropping a board item on it dispatches `{ type: 'storeInPantry', cell }`. It highlights when it has a `data-dragging` attribute.
- Pressing the button toggles a drawer in `overlayRoot`, sitting just above the tray (`bottom: var(--tray-height)`), full column width, showing one tile per slot: item art for filled slots, a dashed outline for empty ones. The open drawer is also a drop zone for storing. Under the tiles, a "Buy slot — N coins" button dispatches `{ type: 'buyPantrySlot' }`; it is disabled when `canAffordSlot` is false and hidden when `nextSlotCost` is null.
- Dragging out: a pointer-down on a filled tile starts a drag once the pointer moves 6 px. A copy of the item's image follows the pointer (`position: fixed`, pointer capture, `touch-action: none` on tiles). On pointer-up over the board (`board.cellAt` returns a cell), dispatch `{ type: 'takeFromPantry', pantryIndex, to }`. Anywhere else cancels.
- Re-render on every store notification. Import pantryDrawer.css from pantryDrawer.ts; use the tokens.

In src/main.ts, add below `// UI mounts`: `mountPantryDrawer(tray, overlayRoot, store, boardView);`.

Rules: no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/ui/pantryModel.test.ts` passes, with tests (using `stateWith` from src/core/testing.ts) for: an empty 4-slot Pantry; a partly filled one; the next slot's cost; too few coins; every slot bought. `npm run build` succeeds. The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
