Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Order`, `Customer`), src/core/deliver.ts (`matchOrderItems`), src/ui/store.ts, src/render/assets.ts (`setImageArt`), src/main.ts, src/ui/app.css, src/ui/tokens.css, docs/briefs/working-rules.md.

Goal: Show the customers' orders above the board, mark which wanted items are ready, and deliver filled orders.

Files to create or edit: src/ui/counterModel.ts, src/ui/counterModel.test.ts, src/ui/counterStrip.ts, src/ui/counterStrip.css, src/main.ts (one line). Do not edit any other file.
Contract:

```ts
// src/ui/counterModel.ts — pure, no DOM
export interface OrderCard {
  orderId: OrderId;
  customerName: string;
  portraitKey: string;
  wants: { itemId: ItemId; name: string; spriteKey: string; ready: boolean }[];
  coins: number;
  stars: number;
  fillable: boolean;
}
/** One card per open order, in order. `ready` comes from matchOrderItems; fillable when every item is ready. */
export function counterCards(data: GameData, state: GameState): OrderCard[];

// src/ui/counterStrip.ts
export function mountCounterStrip(counter: HTMLElement, store: GameStore): void;
```

The strip fills `#counter` with up to 4 cards in a row that fits a 320 px wide screen. Each card has the customer's portrait (`setImageArt` with `portraitKey`; placeholders are expected for now), name, a bubble of the wanted items' art with a check mark on ready ones, the reward (coins and stars, as text), and a "Deliver" button that is enabled only when `fillable` and dispatches `{ type: 'deliverOrder', orderId }`. Re-render on every store notification. Import counterStrip.css from counterStrip.ts; use the tokens in src/ui/tokens.css.

In src/main.ts, add below `// UI mounts`: `mountCounterStrip(counter, store);`.
