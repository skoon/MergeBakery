# Task T4.2: Bake status, collecting, and rushing

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`Bake`, `BakeSlotRef`, `ActionResult`, `GameEvent`), src/core/kitchen.ts (T4.1: `getBake`, `setBake`), src/core/board.ts, src/core/discovery.ts, src/core/testing.ts, src/data/economy.json (`rushGemsPerMinute`), docs/briefs/working-rules.md.

Goal: Tell how far along a bake is, move finished bakes onto the board, and let players pay gems to finish one now.

Files to create or edit: src/core/bakes.ts, src/core/bakes.test.ts. Do not edit any other file.
Contract (all throw RangeError for a bad slot, via `getBake`):

```ts
export type BakeStatus =
  | { kind: 'empty' }
  | { kind: 'baking'; recipeId: RecipeId; progress: number; msLeft: number } // progress 0–1 from startedAt to endsAt
  | { kind: 'done'; recipeId: RecipeId };
export function bakeStatus(
  state: GameState,
  slot: BakeSlotRef,
  now: Timestamp,
): BakeStatus;
/**
 * Rejects 'slotEmpty' and 'bakeNotReady' (now < endsAt). Puts the recipe's output item (not
 * cobwebbed, generator: null) at nearestEmpty(board, the middle cell: row floor(rows / 2), col
 * floor(cols / 2)); if the board is full, at the end of the Pantry; if that is full too, rejects
 * 'boardFull' and the bake stays waiting. Empties the slot and runs `discover` on the output.
 * Events: bakeCollected { slot, itemId, to: { cell } or 'pantry' }, then any `discovered`.
 */
export function collectBake(
  data: GameData,
  state: GameState,
  slot: BakeSlotRef,
  now: Timestamp,
): ActionResult;
/** Gems to finish now: ceil(msLeft / 60 000) × rushGemsPerMinute; 0 for a finished bake. Throws for an empty slot. */
export function rushCost(
  data: GameData,
  state: GameState,
  slot: BakeSlotRef,
  now: Timestamp,
): number;
/**
 * Rejects 'slotEmpty'. A finished bake returns ok with the same state and no events.
 * Rejects 'notEnoughGems' when gems < rushCost. Otherwise gems − cost and endsAt = now. No events.
 */
export function rushBake(
  data: GameData,
  state: GameState,
  slot: BakeSlotRef,
  now: Timestamp,
): ActionResult;
```

Build baking states with `stateWith(cells, { kitchen: { ovens: [{ ovenId: 'toaster-oven', slots: [{ recipeId: 'bake-croissant', startedAt: 0, endsAt: 300000 }] }] } })`.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/core/bakes.test.ts` passes, with tests for: each status (empty, halfway at progress 0.5, done exactly at endsAt); collecting onto the board near the middle; collecting into the Pantry when the board is full; a full board and full Pantry (rejected, state unchanged); collecting too early and from an empty slot; the `discovered` event for a first croissant; rush cost rounding up (1 ms left costs 1 minute); rushing with and without enough gems; rushing a finished bake. The checks in working-rules.md pass.
