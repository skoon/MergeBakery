# Task T4.3: Oven upgrades

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: src/core/types.ts (`OvenDef`, `OvenState`, `Bake`, `ActionResult`, `RejectReason`), src/core/kitchen.ts (T4.1), src/core/testing.ts, src/data/ovens.json, docs/briefs/working-rules.md.

Goal: Merging two identical ovens in the Kitchen makes the next oven tier, with one more slot and a faster bake multiplier, without disturbing running bakes.

Files to create or edit: src/core/ovens.ts, src/core/ovens.test.ts. Do not edit any other file.
Contract:

```ts
/** The oven one tier up, or null at the top tier. Throws on an unknown id. */
export function nextOven(data: GameData, ovenId: OvenId): OvenDef | null;
/**
 * Merges kitchen.ovens[from] into kitchen.ovens[to]. Throws RangeError for an index that doesn't exist.
 * Rejects, in order: 'sameCell' when from === to; 'ovensDontMatch' when their oven ids differ;
 * 'ovenMaxTier' when there is no next tier; 'slotBusy' when the two ovens hold more bakes
 * (running or finished) than the new oven has slots.
 * Otherwise the upgraded oven takes `to`'s place in the list. Its slots are `to`'s bakes, then
 * `from`'s bakes (each in slot order, skipping empty slots), then null up to its slot count.
 * `from` is removed from the list. Bakes keep their startedAt and endsAt; the new multiplier
 * only applies to bakes loaded later.
 * Event: ovenUpgraded { oven: the upgraded oven's index after `from` is removed, ovenId }.
 */
export function mergeOvens(
  data: GameData,
  state: GameState,
  from: number,
  to: number,
): ActionResult;
```

Chapter 1 starts with one Toaster Oven, so tests set `kitchen` through `stateWith`'s overrides.

Rules: pure functions in src/core; no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npx vitest run src/core/ovens.test.ts` passes, with tests for: two empty Toaster Ovens becoming a Brick Oven with 2 empty slots; running bakes keeping their endsAt and landing in the new slots; the new slot appearing; two Brick Ovens holding 4 bakes (rejected 'slotBusy') and holding 3 (allowed, Deck Oven with 3 bakes); the returned index when `from` comes before `to` and after it; each reject reason; a bad index throwing. The checks in working-rules.md pass.
If the contract seems wrong, stop and explain instead of changing it.
