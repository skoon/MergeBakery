## Contract

```ts
// src/ui/kitchenModel.ts — pure, no DOM
export interface SlotView {
  slot: BakeSlotRef;
  status: BakeStatus; // from bakes.ts
  recipeName: string | null;
  timeLeft: string | null; // formatDuration(msLeft) while baking, else null
  rushCost: number | null; // while baking, else null
  canAffordRush: boolean;
}
export interface OvenView {
  index: number;
  ovenId: OvenId;
  name: string;
  slots: SlotView[];
}
export interface RecipeView {
  recipeId: RecipeId;
  name: string;
  outputSpriteKey: string;
  inputs: { itemId: ItemId; name: string; spriteKey: string; ready: boolean }[];
  /** Board cells for the inputs, in recipe order, when every input is on the board; else null. */
  cells: CellIndex[] | null;
  bakeTime: string; // formatDuration of the bake in the oven of `freeSlot`, else the first oven
}
export interface KitchenModel {
  ovens: OvenView[];
  recipes: RecipeView[]; // every recipe, in data order
  /** The first empty slot, scanning ovens then slots in order; null when all are busy. */
  freeSlot: BakeSlotRef | null;
  /** For the button ring: the highest progress among baking slots, or null when none is baking. */
  ringProgress: number | null;
  doneCount: number;
  /** The first pair of ovens with the same id and a next tier: `to` is the earlier index. Null when none. */
  upgrade: { from: number; to: number; nextName: string } | null;
}
/** "m:ss" under an hour, else "h:mm:ss"; seconds rounded up. */
export function formatDuration(ms: number): string;
export function kitchenModel(
  data: GameData,
  state: GameState,
  now: Timestamp,
): KitchenModel;
/**
 * For a board item dropped on the Oven button: the first recipe, in data order, that uses the
 * item and has all its inputs on the board (using `cell` for the dropped item), with its cells
 * in recipe order and the first free slot. Null when none qualifies or no slot is free.
 */
export function recipeForDrop(
  data: GameData,
  state: GameState,
  cell: CellIndex,
): { recipeId: RecipeId; cells: CellIndex[]; slot: BakeSlotRef } | null;

// src/ui/kitchenSheet.ts
export function mountKitchen(
  tray: HTMLElement,
  overlayRoot: HTMLElement,
  store: GameStore,
  clock: () => Timestamp,
): void;
```

## Behavior

- **Oven button:** centered in the tray (`position: absolute; left: 50%; transform: translateX(-50%)`), labeled "Oven", with an SVG progress ring around it filled to `ringProgress` and a small badge showing `doneCount` when above 0. It is a drop zone (`registerDropZone`): on drop, `recipeForDrop` → dispatch `{ type: 'loadRecipe', slot, recipeId, cells }`; when it returns null, open the sheet instead. It highlights when it has a `data-dragging` attribute. Pressing it toggles the sheet.
- **Kitchen sheet:** in `overlayRoot`, anchored just above the tray (`bottom: var(--tray-height)`), full column width, half the column's height, scrolling inside, drawn above the Pantry drawer (higher `z-index`). Contents, top to bottom:
  - Each oven: its name, then one row per slot: "Empty"; or the recipe name, time left, a progress bar, and "Rush — N gems" (disabled when unaffordable) dispatching `rushBake`; or "Ready" with a "Collect" button dispatching `collectBake`.
  - When `upgrade` isn't null: an "Upgrade to <nextName>" button dispatching `{ type: 'mergeOvens', from, to }`.
  - Each recipe: output art and name, input art with a check on ready inputs, bake time, and a "Send to Oven" button enabled when `cells` and `freeSlot` are both non-null, dispatching `loadRecipe`.
  - An empty `<div class="kitchen-extras">` at the bottom (task T4.9 adds a setting there).
- Re-render on every store notification, and once a second for the timers and ring.
- Import kitchenSheet.css from kitchenSheet.ts; use the tokens; fit a 320 px wide screen.

In src/main.ts, add below `// UI mounts`: `mountKitchen(tray, overlayRoot, store, () => Date.now());` (small Edit calls only). The phase-end review connects `loadRecipe`, `collectBake`, `rushBake` and `mergeOvens` in dispatch.ts; don't edit it.
