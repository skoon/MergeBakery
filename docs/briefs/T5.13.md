# Task T5.13: Installable app (PWA)

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: vite.config.ts, tsconfig.json, index.html, src/main.ts, package.json, public/icons/ (the app icons, already provided), docs/briefs/working-rules.md.

Goal: The game installs to a phone's home screen or the desktop like an app and keeps working with no connection once it has loaded once.

Files to create or edit: package.json and package-lock.json (through `npm install` only), vite.config.ts, tsconfig.json, index.html, src/main.ts. Do not edit any other file.

**This task may add one dependency: `vite-plugin-pwa`**, approved by Scott, as a dev dependency. It is the only exception to working-rules.md's no-new-dependencies rule. Run exactly `npm install --save-dev vite-plugin-pwa`, and only after checking no other session is running `npm` in this folder (see working-rules.md).

## What to build

- **vite.config.ts:** add `VitePWA` with `registerType: 'autoUpdate'` and:
  - `manifest`: name "Rise & Shine Bakery", short_name "Rise & Shine", description "A cozy merge game about reopening Grandma's bakery.", `theme_color` `#9c5b2e` (crust), `background_color` `#fff6e6` (cream), `display` `standalone`, `orientation` `portrait`, `start_url` and `scope` `./`, and icons `icons/icon-192.png` (192×192), `icons/icon-512.png` (512×512) and `icons/icon-maskable-512.png` (512×512, `purpose: 'maskable'`).
  - `workbox.globPatterns`: `['**/*.{js,css,html,svg,png,json,webmanifest}']`, so every art file is cached for offline play. Raise `maximumFileSizeToCacheInBytes` only if the build says a file was skipped.
  - Keep the existing `test` block.
- **index.html:** `<meta name="theme-color" content="#9c5b2e">` and `<link rel="apple-touch-icon" href="/icons/icon-192.png">`.
- **tsconfig.json:** add `vite-plugin-pwa/client` to `types`.
- **main.ts:** register the service worker with `registerSW({ immediate: true })` from `virtual:pwa-register`. With `autoUpdate`, a new version takes over on the next load. Saves live in localStorage, not the cache, so an update never touches them.
- The service worker must not run in `npm run dev` (the plugin's default), so the dev-only console tools and hot reload keep working.

Rules: no edits to types.ts; follow docs/briefs/working-rules.md.

Done when: `npm run build` succeeds and `dist/` contains `manifest.webmanifest` with the fields above and `sw.js`, and the build log lists the art in the precache (delete dist/ afterwards). `npm run typecheck` and `npm test` pass. The checks in working-rules.md pass. The phase-end review checks in Chrome (from `npm run preview`) that the install prompt appears on Android and desktop, and that the game reloads and plays with the network turned off.
If the contract seems wrong, stop and explain instead of changing it.
