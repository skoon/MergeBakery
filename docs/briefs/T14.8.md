# Task T14.8: Season UI

Context: Rise & Shine Bakery, a browser merge game (TypeScript, Vite, PixiJS, Vitest).
Read first: `implementation_plan.md` section 2 ("Invitation", "Reward track", "End", "Theme"), `src/core/seasons.ts`, `src/seasons/pack.ts`, `src/seasons/loader.ts`, `src/ui/eventSheet.ts` and `eventModel.ts` (the MegaBun pattern this follows), `src/audio/music.ts`, `src/ui/dialogue.ts`, `src/ui/devTools.ts`, docs/briefs/working-rules.md.

Goal: the player can see, join and play a season: a season button in the top bar, a one-time invitation, a season sheet with points and the milestone track, a result card when it ends, and keepsakes on a shelf in the Bakery screen. While a joined season runs, its theme (colours, music) applies and its intro scene plays on joining. Dev tools force a season open and end one now.

Branch: `t14.8-season-ui` (off `t14.7-pack-build`). Built in the same uncommitted working tree; the Files table is the split for the commit.

## The theme in season.json

```json
"theme": {
  "invitation": "Harvest Supper has come to the harbor. Join in?",
  "tokens": { "--color-crust": "#b5652b", "--color-butter": "#f2b25c" },
  "music": { "bpm": 80, "rootHz": 220, "wave": "triangle", "gain": 0.06, "pattern": [0, 1, 2, 1, 0, 2, 1, 2], "progression": [[0, 3, 7], [5, 8, 12]] },
  "intro": [{ "speaker": "grandma", "expression": "happy", "text": "..." }]
}
```

Every field is optional, and so is `theme`. `SeasonDef` is frozen, so the theme travels beside it: `parseSeasonPack` returns it as `SeasonPack.theme`, the loader returns `themes` (season id → theme) for the packs that loaded, and `main.ts` hands it to the UI. Core never sees it.

## Decisions (defaults, recorded under /goal)

1. **Tokens** may only override names `tokens.css` declares; `pack.ts` checks the `--name` shape, and the pack build and `sources.test.ts` check each name against `tokens.css`. They apply on the page root only while the joined season runs (`runningSeason`), and are removed when it ends. Not joined: no theme, as the plan says.
2. **No board background sprite yet.** Packs have only emoji placeholder tiles, which can't make a background; overriding `--color-cream` already recolours the board's surroundings. It can be added once a season has drawn art.
3. **Music** is a theme in `music.json`'s shape, checked with `parseMusic`; while the season runs it plays instead of the chapter's theme, switching at the next bar line.
4. **Intro** lines use the dialogue line format and speakers, checked with `parseScenes` when the pack is parsed (a bad line skips the pack, never the game). They become scene `<id>-intro`, played on `seasonJoined`.
5. **Button**: a pill in the top chrome, like the MegaBun pill. Shown when a loaded season's window is open, the tutorial is done and no other season is joined ("New season" tag), and while a season is joined (time left, a badge with milestones ready to claim). Hidden otherwise.
6. **Invitation card**: the first time the button offers a season's run, a card invites the player: the theme's `invitation` text or a default, "Join" and "Not now". Seen runs are kept in localStorage (`rise-and-shine-season-invites`, keys `<id>@<startsAt>`), so next year's run invites again. A storage failure logs and shows the card again next load.
7. **Sheet**: not joined, the invitation text, the milestone track (locked) and Join; joined but waiting, why it hasn't started (a MegaBun event is running, or no room for its generator); running, Season Points, how to play, and the track with Claim buttons. A keepsake reward is named in the track.
8. **Result card** (z-index as the event result): "<name> is over", Season Points, coins for seasonal items sold, and the keepsakes earned this run; OK dispatches `dismissSeasonResult`.
9. **Keepsake shelf**: under the trophies on the Bakery screen, each keepsake's art, name and year, in the order earned. Art resolves through T14.6's season art registry; a keepsake whose season left the index would show the `_missing` placeholder (T14.7 prevents that).
10. **Dev tools**: `bakery.season('thanksgiving')` saves a dev-only localStorage key and reloads; `main.ts` (DEV only) passes it to `loadSeasons` as `forceOpen`, which loads that season and starts its window now (it still ends on its own last day, which `seasonYear` needs). `bakery.season(null)` clears it. `bakery.endSeason()` sets the joined season's `endsAt` to now and reloads, so the first tick ends it and the result card shows; it also clears the force key.
